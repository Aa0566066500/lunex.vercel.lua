# Lunex Scripts

منصة لإدارة وحفظ سورسات Lua بواجهة عربية وتصميم حديث.

## المميزات

- تسجيل الدخول باستخدام Google عبر Firebase Authentication.
- مساحة خاصة لكل مستخدم.
- إنشاء سورسات Lua وتعديلها وحذفها.
- اختيار اسم رابط مخصص لكل سورس.
- التحقق من عدم تكرار أسماء الروابط.
- قاعدة بيانات PostgreSQL.
- التحقق من صلاحيات الوصول إلى السورسات على الخادم.
- لوحة صلاحيات إدارية تعتمد على البريد الإلكتروني.
- الوضع الفاتح والداكن.
- واجهة متوافقة مع الهواتف والأجهزة اللوحية.

## متطلبات المشروع

- Node.js.
- حساب Vercel.
- مشروع Firebase.
- قاعدة بيانات PostgreSQL.
- إعداد متغيرات البيئة المطلوبة.
